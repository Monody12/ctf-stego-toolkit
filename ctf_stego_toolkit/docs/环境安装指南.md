# 环境安装指南

本项目核心可在 Python 3.9+ 上运行。外部工具是增强项；缺失时工具会继续跑，并在日志中提示缺少哪些能力。

## 本机环境记录

当前环境：CentOS Stream 9，Python 3.9.25。

已验证可用：

- `file`, `strings`, `xxd`
- `exiftool`
- `binwalk`
- `pngcheck`
- `zsteg`
- ImageMagick: `convert`, `identify`
- `tesseract`
- `gocr`
- `zbarimg`
- `qrencode`
- `ffmpeg`
- `bpgdec`
- Python 包：`Pillow`, `numpy`

本次新增安装：

```bash
dnf install -y tesseract tesseract-langpack-eng
dnf install -y ffmpeg-free
dnf install -y gocr
dnf install -y zbar qrencode
```

BPG 解码器通过源码安装：

```bash
cd /tmp
wget https://bellard.org/bpg/libbpg-0.9.8.tar.gz
tar xf libbpg-0.9.8.tar.gz
cd libbpg-0.9.8
make bpgdec
install -m 0755 bpgdec /usr/local/bin/bpgdec
```

`steghide` 在当前 CentOS Stream 9 仓库中未找到可直接安装包；工具会检测缺失并提示。后续如遇 steghide 题，CentOS/RHEL 建议源码编译或换 Kali/Ubuntu 环境。

## CentOS/RHEL/Fedora

```bash
dnf install -y python3 python3-pip file binutils vim-common
dnf install -y perl-Image-ExifTool pngcheck ImageMagick ruby tesseract gocr zbar qrencode
gem install zsteg
dnf install -y ffmpeg-free
python3 -m pip install -r ctf_stego_toolkit/requirements.txt
```

若 `pngcheck`、`gocr` 等包不可用，先启用 EPEL/CRB。

## Ubuntu/Kali/Debian

```bash
sudo apt update
sudo apt install -y python3 python3-pip file binutils xxd
sudo apt install -y libimage-exiftool-perl binwalk pngcheck imagemagick
sudo apt install -y ruby tesseract-ocr gocr ffmpeg steghide foremost gifsicle
sudo apt install -y zbar-tools qrencode outguess
sudo gem install zsteg
python3 -m pip install -r ctf_stego_toolkit/requirements.txt
```

## 环境自检

运行任意题时都会打印环境检测：

```bash
python3 ctf_stego_toolkit/solve.py questions/challenges/misc41/misc41.jpg --no-color
```

缺失工具会显示为 `! 工具名 缺失`，并给出安装提示。

## 密码型 JPEG 隐写工具

这类工具一般需要题目给密码或字典，项目默认只检测环境并提示，不做长时间爆破：

- `steghide`
- `stegseek`
- `outguess`
- `jphide`
- `openstego`

Kali/Ubuntu 环境通常更容易安装这些工具；CentOS/RHEL 上部分工具需要源码编译、下载 release 二进制或使用容器。

## WebUI 依赖（可选）

本地图形看板仅需两个纯 Python 包（Flask + Flask-SQLAlchemy），无前端构建步骤：

```bash
python3 -m pip install -e ".[webui]"
./webui-start.sh   # 一键启动, 默认 http://127.0.0.1:8800（停止用 ./webui-stop.sh）
```

离线环境预载（在有网的机器上执行后把 wheels/ 目录拷过去）：

```bash
python3 -m pip download ".[webui]" -d wheels/
python3 -m pip install --no-index --find-links wheels/ -e .
```

数据目录默认 `<仓库根>/webui_data/`（SQLite + 题目文件 + flag 前缀配置），可用
`ctf-stego-webui --data-dir <路径>` 或环境变量 `STEGO_WEBUI_DATA` 指定。
