# 通用图片隐写能力审计

本项目覆盖常见 CTF 图片隐写考点，但通用 CTF 图片隐写范围更大。下面是当前覆盖与缺口。

## 已覆盖或已增强

- 明文 flag、UTF-16、hex/base64、常见压缩容器递归扫描。
- PNG/JPEG/GIF/BMP/TIFF/WebP/BPG 基础识别。
- IEND/FFD9/GIF trailer/BMP 像素区后附加数据。
- ZIP/gzip/zlib/bzip2/LZMA/XZ 解压扫描。
- 7z/RAR/TAR/PDF/ELF/PSD/WEBP 等嵌入文件头嗅探与保存。
- PNG chunk、IDAT、CRC、APNG delay 编码。
- GIF delay、异常帧、宽高修复。
- JPEG/BMP/GIF/PNG 常见宽高修复。
- zsteg PNG/BMP LSB 文本和 extradata 提取。
- RGB/A 低位位平面接触图与 RGB bit0/bit1 重建图。
- QR/条码自动识别：`zbarimg` 扫描原图、提取图、位平面图。
- OCR：tesseract + gocr；保存增强图、彩色文字掩码、文本裁剪图。

## 仍不完美的考点

| 类别 | 现状 | 后续建议 |
| --- | --- | --- |
| 密码型 JPEG 隐写 | 只检测/提示 steghide、stegseek、outguess、jphide、openstego | 增加 `--wordlist` 参数后再允许显式爆破 |
| 盲水印/差分图 | 没有通用自动恢复 | 增加双图输入模式：`--compare original.png suspect.png` |
| DCT/频域隐写 | 未内置 F5/JSteg/OutGuess 解码 | 接入专业工具并记录失败提示 |
| 调色板隐写 | 只靠 zsteg/位平面间接发现 | 增加 PNG PLTE/tRNS 顺序、索引 LSB 分析 |
| LSB matching/随机 LSB | 无密钥时不可稳定恢复 | 增加统计异常提示，不承诺自动还原 |
| 艺术字/低对比度视觉题 | OCR 有误差，保存可读图供人工 | 可接入视觉模型或专用像素字体模板 |
| 加密压缩包 | 可检测保存，不能无密码解密 | 增加 hash 提取/John 提示，显式授权后爆破 |
| 多媒体混合 | ffmpeg 已检测，但视频/音频频谱规则少 | 增加 GIF/视频抽帧、音频频谱/LSB 模块 |

## 本轮新增能力验证

- 安装并检测 `zbarimg`。
- 新增 `BarcodeAnalyzer`，可自动读取 QR/条码内容并扫描 flag。
- 新增 `BitPlaneAnalyzer`，生成低位位平面图，供条码/OCR/人工继续分析。
- 增强 `ExtraDataAnalyzer` 的文件头嗅探。
- 增强 JPEG 密码型隐写提示。
